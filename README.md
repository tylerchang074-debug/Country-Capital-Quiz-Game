# Capital Quiz

A Tkinter quiz game that asks capital city questions across three difficulty levels.

## Features
- Easy/Medium/Hard difficulty selection
- Shuffled questions, no repeats
- Score tracking with a hint option (costs 1 point)
- Play again without restarting the program

## How to run
python3 capital_quiz.py

## What I learned
Debugging silent Tkinter bugs, variable name collisions, and event bindings that fail without throwing an error.
